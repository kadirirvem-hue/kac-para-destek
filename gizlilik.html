kac-para-cli — Privacy Policy

Last updated: 27 August 2026

Summary: this tool collects no personal data from anyone. It has exactly one user — its owner — and it stores no YouTube data.

1. Who this covers

kac-para-cli is a personal command-line tool run locally by its owner. It is not distributed and has no other users, so there is no user base whose data could be collected.

2. Data collected

None. The tool does not collect, request, or receive personal information from any person. There is no analytics, no telemetry, no tracking and no crash reporting.

3. YouTube data

The tool calls two YouTube Data API endpoints:

  • videos.insert — to upload a video to the owner's own channel
  • channels.list (mine=true) — to confirm the authorisation is bound to the correct channel

The only value retained is the video ID returned after an upload, written to a local text file on the owner's own machine so the same video is not uploaded twice. No other YouTube data is stored, cached, processed, displayed, transferred or sold. No YouTube data is shared with any third party.

4. YouTube Terms and Google Privacy Policy

This tool uses YouTube API Services. By using it, the owner agrees to be bound by the YouTube Terms of Service. Google's handling of any data it receives is governed by the Google Privacy Policy (https://policies.google.com/privacy).

5. Deleting data and revoking access

The only stored value is a video ID in a local text file on the owner's own machine; deleting that file removes it completely. There is no server-side copy, no database and no backup, so there is nothing for the owner to request deletion of from a third party.

API access can be revoked at any time from the Google security settings page at https://myaccount.google.com/permissions, which immediately and permanently ends the tool's access to the account. Any locally stored OAuth token can be deleted by removing the local environment file.

Because the tool collects no data from any other person, there are no third-party data subject requests to handle. Questions may be sent to rakamstudyo@gmail.com.

6. Credentials

The OAuth refresh token and API credentials are stored in a local environment file on the owner's own machine. They are never transmitted anywhere except to Google's own authentication endpoints. Authorisation can be revoked at any time from the owner's Google Account security settings.

7. Third parties

No data is shared with third parties. The tool has no server, no database and no backend of any kind.

8. Children

The tool is not directed at children and has no users other than its owner.

9. Changes

Any change to this policy will be published on this page with an updated date.

10. Contact

Gizlilik Politikası (Türkçe)

Özet: bu araç hiç kimseden kişisel veri toplamaz. Tek kullanıcısı sahibidir ve hiçbir YouTube verisi saklamaz.

Araç yerel olarak sahibinin kendi bilgisayarında çalışır. Analitik, telemetri, takip ve çökme raporlaması yoktur. Sunucusu, veritabanı ve arka ucu yoktur.

Yükleme sonrası dönen video kimliği, aynı videonun iki kez yüklenmemesi için yerel bir metin dosyasına yazılır. Başka hiçbir YouTube verisi saklanmaz, işlenmez, gösterilmez, aktarılmaz ya da satılmaz.

Araç YouTube API Servisleri'ni kullanır ve YouTube Hizmet Şartları'na tabidir. Google'ın aldığı verileri işleyişi Google Gizlilik Politikası (https://policies.google.com/privacy) kapsamındadır.

Silme ve yetki iptali: saklanan tek değer yerel bir metin dosyasındaki video kimliğidir; dosyayı silmek onu tamamen kaldırır. Sunucu kopyası, veritabanı ya da yedek yoktur. API yetkisi https://myaccount.google.com/permissions adresinden istenildiği an kalıcı olarak iptal edilebilir.

OAuth yenileme anahtarı yalnızca yerel ortam dosyasında tutulur ve Google'ın kendi kimlik doğrulama uçları dışında hiçbir yere gönderilmez. Yetki, Google Hesabı güvenlik ayarlarından istenildiği zaman iptal edilebilir.
