kac-para-cli is a personal command-line tool that uploads videos to its owner's own YouTube channel, Kaç Para?.

Who uses it

One person: the developer and channel owner. The tool is not distributed, not sold, not offered to any other user, and is not a public product or service. There is no sign-up, no user account system and no third-party access.

What it does

It generates a short vertical video from data the owner has collected manually, then uploads that video to the owner's own channel. Every number shown in a video comes from a public, cited source.

YouTube API usage

  • videos.insert — uploads a video to the owner's own channel
  • channels.list (mine=true) — confirms the authorisation is bound to the correct channel

No other endpoint is called. Requested quota is the default; the tool performs at most two uploads per day.

Data

The tool collects no user data and stores no YouTube data. See the privacy policy and the terms of service.

Access

The tool has no web interface and no public download. It runs locally on the owner's own machine. Screenshots or a walkthrough can be provided to the YouTube API Services team on request: rakamstudyo@gmail.com
